# Next.js SSR

Пример приложения [Next.js](https://nextjs.org/) с отрисовкой на сервере (SSR), которое можно
развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `3000` |
| Путь проверки состояния | `/` |

Railpack ставит зависимости, собирает проект (`npm run build`) и запускает сервер Next.js
(`npm run start`). Сервер отрисовывает страницу при каждом запросе и слушает порт из переменной
окружения `PORT` — её передаёт платформа, — а без неё `3000`.

В демо нет `package-lock.json`: версии пакетов выбираются при сборке по диапазонам из
`package.json`.

Статическая версия — `app-example-next`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск в режиме разработки с отслеживанием изменений
npm run dev

# сборка и запуск для продакшн
npm run build
npm run start
```

Нужен Node.js 20.9 или новее.
