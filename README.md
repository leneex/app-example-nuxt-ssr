# Nuxt SSR

Пример приложения [Nuxt](https://nuxt.com/) с серверным рендерингом (SSR), которое можно
развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `3000` |
| Путь проверки состояния | `/` |

Railpack ставит зависимости, собирает проект (`npm run build`) и запускает сервер Nuxt
(`node .output/server/index.mjs`). Страницы из `app/pages/` отрисовываются на сервере, на
`/api/hello` отвечает обработчик из `server/api/`. Сервер слушает порт из переменной окружения
`PORT` — её передаёт платформа, — а без неё `3000`.

В демо нет `package-lock.json`: версии пакетов выбираются при сборке по диапазонам из
`package.json`.

Статическая версия — `app-example-nuxt`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
npm install

# запуск в режиме разработки с отслеживанием изменений
npm run dev

# сборка и запуск для продакшн
npm run build
node .output/server/index.mjs
```

Нужен Node.js 24.15 или новее (в ветке 22 — 22.22.3 или новее).
